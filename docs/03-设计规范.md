# 03 设计规范

完整组件代码见 `theme-risksignal-outlier.md`。本页是要点。

## 品牌（来源：RiskSignal 标志使用规范 v1.0，Drive「RiskSignal-logo-1/guide」）

标志含义：圆环是全球市场，跳出圆环的点是值得关注的风险信号。

| 色 | HEX | 用法 |
|---|---|---|
| 墨蓝 Ink | `#0E1726` | 标题、骨架、深色块 |
| 信号橙 Signal | `#F2501E` | **只用于“点”和少量强调**：信号点、看点编号、关键词下划线、关键数字。不做大面积底色；白底对比度仅 3.5:1，**不用于正文文字** |
| 纸白 Paper | `#F6F4EF` | 卡片衬底 |

辅助色（主题内）：正文 `#1F2937`、次要文字 `#5B6575`、深色块上弱化文字 `#9AA6B8`、深色块次级层 `#1C2A40`、分隔线 `#E5E2DA`。

**Logo**：
- 浅底用彩色版，墨蓝/深色底用反白版，单色印刷用黑/白版；横版用于页眉页脚，单独图形用于头像图标。
- 安全空间：四周 ≥ 1 个信号点直径。屏幕最小宽度：横版 120px、竖版 64px。
- 禁止：拉伸、旋转、改色、加阴影/描边/渐变、移动或去掉信号点、在杂乱照片上直接放置。
- 本流程用 `template/logo-reversed.png`（反白横版，已裁切、铺墨蓝底，450×100，在结尾卡上显示 150px 宽）。

**字体**：中文思源黑体 / Noto Sans SC，英文数字 Inter；标题加粗、正文常规；不用衬线和手写体。（渲染环境没有这些字体时，退到苹方等无衬线体。）

## 版面结构（自上而下）

| # | 区块 | 来源 |
|---|---|---|
| 1 | 封面图（全球保险周报 + 栏目串 + 当周日期） | 模板 + 日期 |
| 2 | 每日一图（标签行 + 信息图） | 文档 |
| 3 | 本期看点（3 条橙色编号看点 + 栏目索引药丸） | 每期编辑 |
| 4 | 栏目 ×N：章节标题（编号 01… + 信号点 + 英文标签 + 中文名 + 条数） | 文档 |
| 5 | 快讯 ×M：左竖条标题 → 配图 → 正文（橙色下划线）→ 「来源」标签行 | 文档 + 每期标注 |
| 6 | 结尾互动卡（图片） | 模板 |
| 7 | 声明（纸白卡，NOTICE · 声明） | 模板 |

关键样式：容器最大宽 677px；正文 15px / 行高 1.85 / 两端对齐；快讯标题 17px 粗体 + 3px 墨蓝左竖条；栏目编号 24px 粗体；下划线 `border-bottom:2px solid #F2501E;font-weight:600;color:#0E1726;`；圆角 8px（大块、封面、结尾卡）/ 6px（配图）；无阴影、无渐变。

视觉层级：锚点层（封面、看点编号、结尾卡）≤5 处；标记层（下划线）每段 1–3 处；容器层（纸白卡、竖条标题、来源标签）按需。

## 图片规格（公众号）

| 类型 | 格式 | 宽 | 体积 |
|---|---|---|---|
| 快讯配图、封面 | JPEG（渐进式、去元数据） | 1080px | 按总预算分配，约 ≤140KB（质量 72–88） |
| 每日一图（字小） | PNG | 1600px | ≤1MB |
| 结尾卡 | PNG | 1080px（360px ×3） | ~85KB |

公众号单图上限 10MB；实际瓶颈是成品要上传到 Drive（预览页内嵌全部图片，须 ≤ 约 7.2MB），所以全部图片合计控制在约 5.4MB。透明底一律铺白（结尾 logo 铺墨蓝）。
