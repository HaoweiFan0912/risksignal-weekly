# 01 每周操作流程

适用：用户说「排版某周的周报」。下文 `PKG` = 周报整套流程/。

## 1. 定周

- 周期：**周一 00:00 至周日**。任何一天都可代表所在周，脚本会自动换算到周一、周日。
- 「这周」= 今天所在周；「上周」= 前一周；「11 月 16 日那周」= 含该日的周。年份不明时取离今天最近的那个。
- 周文件夹名：`{周一月}.{周一日}.{周一年}-{周日月}.{周日日}.{周日年}`，不补零。例：`11.16.2026-11.22.2026`、跨年 `12.28.2026-1.3.2027`。

## 2. 找文档（Google Drive）

ID 见 `config.local.json` → `drive`（私密，不在仓库里；新环境照 `config.local.example.json` 新建）。

```
RiskSignal（risksignal_root_folder_id）
└── 热点收集（weekly_parent_folder_id）
    ├── 11.9.2026-11.15.2026/
    │   ├── 周报            ← Google Doc，本流程的输入
    │   ├── 插图/           （作者的配图素材，不需要直接用）
    │   └── …（其他工作文件，忽略）
    └── 11.16.2026-11.22.2026/ …
```

Drive 连接器 `search_files`：

1. `parentId = '<weekly_parent_folder_id>' and title = '11.16.2026-11.22.2026'` → 周文件夹 ID
2. `parentId = '<周文件夹 ID>' and title = '周报' and mimeType = 'application/vnd.google-apps.document'` → 文档 ID

两个 ID 都要记下：文档 ID 给 fetch，周文件夹 ID 用于最后上传成品（`fetch --folder` 会存进 `drive.json`）。

注意：周报文档常有几十 MB（内嵌图片），Drive 连接器的导出接口会报「File too large」。所以正文和图片都从文档公开的 mobilebasic 视图取（`fetch` 自动完成），这要求文档开启「知道链接的人可查看」。

## 3. 文档应有的结构

```
每日一图                       ← 一段文字「每日一图」，下一张图即每日一图
[图片]
# 保险创新                     ← 栏目（Heading 1）
## Neo推短期医疗险，最高保障150万美元   ← 快讯标题（Heading 2）
[图片]                         ← 快讯配图（标题下、正文上）
正文段落……
来源：Coverager，2026年11月9日   ← 来源行（媒体，日期）
## 下一条……
# 风险案例 / 融资 / 并购与合作 / 监管政策 / 相关新闻 …
```

文档里**没有**封面、结尾互动、声明——这些由 `template/` 提供。（2026-11-09 那期之前的旧文档带封面和声明，fetch 会识别并跳过。）

## 4. fetch

```bash
python3 PKG/scripts/make_weekly.py fetch --doc <DOC_ID> --folder <周文件夹ID> --week 2026-11-16
```

它会：下载 mobilebasic 正文 → 解析为 `weekly.md` → 按上下文给图片定位（每日一图 / 所属快讯）→ 下载原尺寸图片到 `配图/原图` → 用 `template/cover-base.png` + 当周日期生成封面 → 按公众号规格处理全部图片到 `配图/公众号` → 写 `manifest.json` 和 `marks.txt` 骨架 → 打印栏目、快讯清单和 WARNING。

WARNING 的处理：

| WARNING | 处理 |
|---|---|
| 栏目名已更正（风险案列 → 风险案例） | 无需处理，交付时提一句 |
| 栏目没有英文标签映射 | 在 `config.json` 的 `section_en` 加一行，重新 fetch |
| 开头非「每日一图」的图片 / 来源行之后多出的文字 | 多为旧版封面、声明，已跳过；确认不是正文 |
| 某条没有配图 / 来源 / 正文 | 告知用户；配图缺失时该条只有文字 |
| 没有每日一图 | 版面会直接从「本期看点」开始，告知用户 |

## 5. 校对 weekly.md 与写 marks.txt

**校对**：只改明显错别字（标题、正文、来源），不改写、不增删内容。改标题后图片会按文档顺序回退匹配（build 会打印 WARNING，核对一下）。每处修改记下来交付时告诉用户。

**marks.txt**：

```
看点：Cowbell | AI 代理闯祸有了独立保单，Cowbell AI 责任险 2027 年开售
看点：USI | 怡安 170 亿美元全现金收购 USI，KKR 预计获约 20 亿美元收益
看点：中国保险业 | 前 3 季原保费 5.26 万亿元，协会发布商业医疗险示范条款

Neo推短期医疗险，最高保 :: 最高给付限额可达150万美元 || 并非全面重大医疗保障
Relay AI替代理人填报 :: 自动填写比价系统与保险公司门户 || 减少同一客户信息在多个系统间重复填写
```

- **看点（3 条）**：全期最有分量的 3 条——新产品首发、大额交易、重要政策/行业数据，尽量分属不同栏目。格式 `看点：<标题里出现的关键词> | <一句话，30 字内，用中文与阿拉伯数字之间留空格的写法>`。
- **下划线**：每条快讯一行，每段 1–3 个短语，优先**核心结论、关键数字、专有名词/新概念、风险提示**（如「并非……」「不等于……」）。短语 4–15 字，必须与正文逐字一致（含全角标点、引号样式）。不要整句划线，不要每段都划同类数字。
- 标题前缀取标题开头十几个字即可，能唯一对应一条快讯。
- 示例：`examples/11.9.2026-11.15.2026/marks.txt`（已发布那期，64 处下划线）。

## 6. build

```bash
python3 PKG/scripts/make_weekly.py build --week 2026-11-16
```

套用 marks（短语找不到、前缀不匹配、看点关键词不存在 → 直接报错退出）→ 生成相对路径版 HTML 与内嵌图片的预览页 → 两者都跑公众号合规校验。没标注的快讯会打印 WARNING。

产物（`<output_root>/<周文件夹名>/`）：

| 文件 | 用途 |
|---|---|
| `周报_排版_异常点(risksignal-outlier)_预览.html` | **交付物**：内嵌全部图片，右上角「复制到公众号」 |
| `周报_排版_异常点(risksignal-outlier).html` | 干净正文（相对路径引图），兜底/存档 |
| `weekly.md` / `marks.txt` / `weekly.marked.md` | 原文 / 标注 / 合成源 |
| `配图/原图`、`配图/公众号`、`manifest.json` | 图片与清单（01 封面、02 每日一图、03 起按快讯顺序） |

## 7. 上传到 Drive 当周文件夹

build 结束会写 `upload.json`：

```json
{
 "local_path": ".../周报_排版_异常点(risksignal-outlier)_预览.html",
 "size_mb": 6.75,
 "file_reference": "sha256:<64位hash>:<绝对路径>",
 "title": "周报_公众号排版_11.9.2026-11.15.2026.html",
 "parent_id": "<周文件夹ID>",
 "contentMimeType": "text/html",
 "disableConversionToGoogleType": true
}
```

Drive 连接器操作：

1. `search_files`：`parentId = '<parent_id>' and title = '<title>'` —— 记下已存在的旧版（重做同一周时会有）。
2. `create_file`：字段照抄 upload.json；`base64Content` 填 `file_reference`（文件引用，应用会在用户批准后读取本地文件，不要把文件内容转成 base64 贴进对话）。
3. 核对返回的 `fileSize` 与本地文件字节数一致。
4. 新版成功后，旧版 `trash_file`（回收站可恢复）；不要永久删除。
5. 把 Drive 链接（返回的 `viewUrl`）告诉用户。

大小限制：连接器单次请求 ≤ 10,000,000 字节，文件内容按 base64（+33%）计，所以预览页须 ≤ 约 7.2MB。`process_imgs.py` 的总预算（`TOTAL_BUDGET_KB = 5400`）保证了这一点：本期 34 张 JPEG 每张 ≤138KB，预览页 6.75MB。快讯特别多时每张上限会自动降低；build 若打印「超过 Drive 上传上限」WARNING，降低预算后重新 fetch。

## 8. 交付

有浏览器工具时先打开预览页确认：图片无坏图、封面日期正确、结尾卡与声明在。预览页约 10MB，用 `file://` 打不开的环境可在输出目录起本地静态服务器查看。

给用户的话包含：
- Drive 上的文件名与链接（及是否替换了旧版）
- 预览页路径 + 用法：「浏览器打开 → 右上角『复制到公众号』→ 公众号编辑器粘贴」
- 本期概况：栏目数、快讯数、图片数
- 改过的错别字列表
- WARNING 及处理结果、需要用户自己处理的事（例如每日一图里的「[公众号名称]」占位文字）

若用户反馈粘贴后图片缺失：按 `配图/公众号/` 的编号补插（01 封面、02 每日一图、03 起依次对应快讯）。
